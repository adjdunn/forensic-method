# Tests and changelog

A prompt change is accepted only if the test cases still pass. Every failure found in testing becomes a method step, a judgment note or a self-check item, and is logged below with the date and the reason. The failure-modes section of the manual's Chapter 12 is written from this file.

## Test set

Files for five companies are built and ready in [../test-data/](../test-data/README.md): Hertz FY2013 (T1), Under Armour FY2016 and Kraft Heinz FY2017 (more enforcement cases), Home Depot FY2025 (T2), CAE FY2026 (T4). T3 (SEDAR+ only) and T5 (held back) are still open.

The original plan, kept for reference: to be selected. Criteria: a mix of frameworks and known difficulties, one company held back and not looked at until the prompts are frozen. Real company names stay in this file and the test log; they never appear in the presentation.

| Slot | Profile | Why | What a passing run must catch |
|---|---|---|---|
| T1 | US GAAP filer with a resolved SEC enforcement history, pre-restatement filings on EDGAR | Turns the case library's "would have been visible" into computed series | The signals the SEC document describes, at the locators it describes |
| T2 | US GAAP filer, acquisitive, clean | Benign-flag stress test | Every acquisition-quarter movement is P4 and cites the context-sheet event |
| T3 | Canadian IFRS filer on SEDAR+ only | Framework and document-structure test | IFRS branches taken; interest-paid classification handled; provisions rollforward read; key audit matters read |
| T4 | Canadian cross-listed 40-F filer | Framework plus EDGAR structure | Same as T3, from EDGAR documents |
| T5 | Held back | Out-of-sample check | Decided before it is opened |

## What every run is scored on

| Measure | How |
|---|---|
| Numbers that tie to the filing | Sample 20 computed values per run; recompute by hand from the pack |
| Locators that open to the right place | Sample 20 locators per run; open each |
| Quotations exact | Every quotation in the sample compared with the filing |
| Benign reading present and first | Every ledger row |
| Context sheet used | Every P4 row cites an event; no row that an event explains is above P4 |
| Consistency checks complete | All ten F4 checks have a result |
| No characterization | Search the output for the banned words |
| Code shown | Every [calc] has code behind it |
| Platform parity | The same pack run on Claude and on ChatGPT; differences logged |

## Open platform questions

- Whether a 21,000-character prompt plus a pack of 20 to 40 files fits in one message and one project on each platform, and on which plans. Untested.
- Whether each platform's code tool reads a multi-sheet xlsx by sheet name without help. Untested.
- Whether long ledger CSVs survive copy and paste between conversations intact. Untested.
