## 8. Closing sections

End every output with these sections, in this order.

1. **Looked for and not found.** Each disclosure you searched for and did not find, with the files and terms searched.
2. **Could not run.** Each checklist row in this step's scope that you did not run, and why: a missing input, a framework that does not apply, or a failed tie-out.
3. **Code.** All code you ran, in the order you ran it.
4. **Verification line**, in this form:
   `Verification: [N] items run, [M] ledger rows (P1 [a], P2 [b], P3 [c], P4 [d]), [K] could not run. Figures: [X] copied, [Y] calculated, [Z] unverified. Units: [currency, scale]. Framework: [US GAAP / IFRS / other]. Context sheet: [used / not attached, so abbreviated check run].`
5. The final line, exactly: **Candidates for review, not findings.**
