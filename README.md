# Forensic Method

Five short prompts that run a forensic accounting review of a public company's filings in a chat assistant, and the test harness that checks what they find. Open source, in testing.

**Start at the page: https://adjdunn.github.io/forensic-method/** It has the idea, how to run the prompts, the prompts themselves with copy buttons, two sample outputs, the test results, and what the method gets wrong. Everything else in this repository is the work behind that page.

## If you want to try it

1. Get a company's statements as a spreadsheet, its last two annual reports, and its last two fourth-quarter results releases. Public documents only.
2. Open the page, copy prompt 1, attach the files to a new Claude or ChatGPT conversation, paste, and read the reply. Then prompt 2 in the same conversation.
3. In a second conversation with the same files: prompt 3, then prompt 4, then prompt 5 with the two replies from the first conversation attached.

The prompts are the files in [`tools/prompts/`](tools/prompts/); the page is built from them. The user guide, with what each file must contain and how to read the results, is [here](https://claude.ai/code/artifact/22260383-1e93-444d-8f9d-6acacf4f4886).

## How it is tested

Every reply is checked the same way: each quotation looked up in the filing and required to be exact and on the cited page; each figure checked against the filing or recomputed; shares of pre-tax income recomputed; banned words and post-cutoff facts flagged. Companies with a known enforcement case get an answer key written from the SEC's order before any run, and an independent scoring agent grades each run against it. A prompt version is promoted only after it has passed in the harness and in one manual run in the chat app.

Where it stands is in [`tools/TESTS.md`](tools/TESTS.md), under "Harness scorecards" and "Platform parity".

## Rules

- Use only the attached documents. The prompts say so, and the checker flags anything from after the filing date.
- Answer keys are scorer-only. A runner's attachment list is an allow-list, never a folder.
- A held-back company and its key are never published, so the out-of-sample claim survives. It lives in a folder the repository ignores.
- Real company names stay in the test record; the companies were chosen because their filings, and for some the SEC's findings, are public.
- Nothing the method raises is a conclusion. Items to investigate; the verdicts are the analyst's.
- No em-dashes anywhere in the package.
